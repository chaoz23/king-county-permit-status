## Where each permit type lives

Every city follows the same shape: building, mechanical/plumbing, land-use and engineering/ROW permits live in the city's system above; **electrical** is WA L&I unless the city self-runs it (then it is in the city's system — and a gap if that system is blocked); **septic** is always King County Public Health; **fire** is the city fire marshal (King County Fire Marshal when unincorporated); **grading** in critical areas may also need King County review inside city limits. The lookup returns this per address as `routing_by_type`.

## Vendors and how they are queried

- **mbp** (live): form POST (parcel-first; applied-date windows beat the result cap); People search for contractors. Cities: Auburn, Bothell, Burien, Federal Way, Issaquah, Kenmore, Kirkland, Mercer Island, Newcastle, Sammamish, Snoqualmie.
- **mbp+arcgis** (live): MyBuildingPermit form POST + Bellevue ArcGIS FeatureServer REST (daily snapshot, 1998+). Cities: Bellevue.
- **mbp+accela** (live): MyBuildingPermit KC jurisdiction + KC Accela global search (older history, enforcement). Cities: King County (unincorporated).
- **energov** (live): Tyler EnerGov JSON API — criteria template + tenant headers, search by parcel. Cities: Renton.
- **civicaccess** (live): Tyler EnerGov Civic Access JSON API — tenant headers, FilterModule=2, 100/page. Cities: Redmond.
- **accela** (live): Accela Citizen Access GlobalSearchResults GET → HTML grid; pager replayed via postback. Cities: Woodinville.
- **etrakit** (live): eTRAKiT VIEWSTATE POST → CSV export; detail page per permit for status (time-boxed). Cities: Shoreline.
- **smartgov** (live): SmartGov form POST with time-based validator token; SearchPage paginator. Cities: Carnation, Normandy Park.
- **lama** (live): LAMA (ASP.NET WebForms) VIEWSTATE POST, filter+sort+200/page in one request. Cities: SeaTac.
- **socrata** (live): Seattle Open Data Socrata REST (4 datasets); parcel queries via the Assessor site address. Cities: Seattle.
- **none** (indexed): No public permit portal; history via the King County Assessor parcel index. Cities: Algona, Beaux Arts Village, Clyde Hill, Hunts Point, Lake Forest Park, Medina, Pacific, Skykomish, Yarrow Point.
- **PermitTrax Citizens Connect** (blocked): Blazor Server over SignalR — the search never issues an HTTP request an adapter could replay. Cities: Black Diamond, Covington, Des Moines, Enumclaw, Milton, North Bend. Tracking: https://github.com/chaoz23/king-county-permit-status/issues/18
- **OpenGov PLC (Turnstile-gated; browser only)** (blocked): Clean JSON:API, but every call needs Cloudflare Turnstile proof-of-possession headers (403 without). Cities: Duvall, Maple Valley. Tracking: https://github.com/chaoz23/king-county-permit-status/issues/21
- **ASP.gov (results require login)** (blocked): Permit results are behind an account login. Cities: Tukwila. Tracking: https://github.com/chaoz23/king-county-permit-status/issues/23
- **No public search — monthly XLSX permit logs + applicant SSO** (blocked): No search at all: monthly XLSX/PDF logs on kentwa.gov plus an applicant-only SSO portal. Cities: Kent. Tracking: https://github.com/chaoz23/king-county-permit-status/issues/24

Per-vendor request recipes and recon notes: https://github.com/chaoz23/king-county-permit-status/blob/main/docs/EPIC-coverage-and-hardening.md. Tool: https://github.com/chaoz23/king-county-permit-status.
